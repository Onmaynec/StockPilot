# StockPilot v0.1.0 — первый рабочий MVP

Первый публичный исходный выпуск StockPilot WMS по ТЗ PV-WMS-01.

## Реализовано

- Многоскладской каталог: товары, SKU, штрихкоды, партии, зоны, ячейки, FIFO и FEFO.
- Приёмка по плану и факту с фиксацией расхождений, перемещения и возвраты.
- Заказы, резервирование с TTL и транзакционные блокировки остатков.
- Задания комплектации, согласование недоборов и проведение отгрузок.
- Инвентаризация с разделением ролей исполнителя и утверждающего.
- JWT-аутентификация и складские права, неизменяемый аудит операций.
- CSV-импорт и экспорт, фильтрация движений, показатели операционной панели.
- React SPA/PWA с мобильным экраном кладовщика.
- Docker Compose: PostgreSQL 16, API, фоновый worker и веб-сервер.

## Запуск

```bash
git clone https://github.com/Onmaynec/StockPilot.git
cd StockPilot
cp .env.example .env
docker compose up -d --build
docker compose exec api python -m app.seed
```

В Windows PowerShell вместо `cp` используйте `Copy-Item`. Адрес приложения: http://localhost:8080. Измените секреты и демонстрационные пароли в `.env` перед развёртыванием.

## Качество и ограничения

Для исходного MVP был настроен CI с API, сборкой интерфейса и Docker Compose; ключевые интеграционные сценарии покрывались тестами. Это MVP для локального стенда, **не подтверждённый production-релиз**. Нагрузочная приёмка AT-10, резервное восстановление AT-11, ручная проверка мобильного устройства AT-12 и полный security-hardening оставались открыты.
