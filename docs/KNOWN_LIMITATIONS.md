# Ограничения v0.1.0

- Итоговые приёмочные испытания и отчёты о p95, 60 пользователях и RTO менее 30 минут не представлены.
- Двухролевые браузерные E2E и аудит безопасности необходимо провести отдельно.
- UI создания заказов ограничен одной строкой; API позволяет несколько строк и несколько складов.
- UI возврата пока требует UUID резерва из деталей заказа.
- Отсутствуют интерфейсы администрирования всех справочников (зоны, ячейки, партии, пользователи); действия доступны через API.
- Нет MFA, revoke, смены пароля и распределённого rate-limit. Перед публичной установкой необходим дополнительный security-hardening.
- При обнаружении новых движений в зоне после снимка утверждение пересчёта отклоняется; требуется повторная инвентаризация, без отдельного автоматического механизма перебазирования.
- Нет настоящей ERP/1С-интеграции. Outbox worker только моделирует доставку.
- PWA не отправляет движения offline: черновики остаются локальными до подключения.
- В demo Compose одна роль PostgreSQL создаёт схему и обслуживает API; в production права следует разделить.
- Описание отражает первую рабочую версию, а не завершение всех 22 функциональных требований.
